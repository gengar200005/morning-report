## 승인 후 한 번 실행하는 방법

승인 대상은 `gengar200005/morning-report`의 **`validation/v1-kis-sample-20261104` 분기에 이 초안을 한 번 push하고 결과를 확인하는 작업**이다. 사용자의 명시적인 push 금지 지침 때문에 별도 승인 전에는 저장소에 반영하거나 실행하지 않는다. 현재까지 이 초안에 대해 commit, push, PR 생성이나 원격 실행을 하지 않았다.

승인 후에는 위 분기에 두 경로의 파일을 한 번 반영하여 이 워크플로 실행 1회를 발생시킨다. `main`과 운영 코드·전략·기존 워크플로는 변경하지 않는다. 별도 승인 없이 재실행하거나 다른 분기에 반영하지 않는다.

워크플로는 지정 저장소·분기에서 두 경로가 변경된 push에만 반응한다. 수동 실행 등록은 필요 없다. 기존 운영 모듈은 가져오거나 실행하지 않으며, 테스트 후 독립 수집기만 실행한다. 기존 `KIS_APP_KEY`, `KIS_APP_SECRET`은 수집 단계에만 전달한다. 키를 채팅이나 파일에 붙여 넣을 필요는 없다.

각 실행은 새 결과 폴더를 만든다. 조회 미완료로 종료 코드 2가 나와도 결과 artifact를 올리고 워크플로 실패 상태는 유지한다. artifact에는 결과 파일과 실행 URL·커밋 기록만 포함하며 보관 기간은 7일이다. 요청별 JSON에는 수집기가 민감값을 제거한 응답을 저장한다.
