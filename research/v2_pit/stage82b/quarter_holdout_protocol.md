# 2021년 2·3·4분기 회계기간 독립 검수 사전등록

1분기 전수 판정 전에 별도로 고정한다. 각 달력분기 말의 마지막 공식 KRX 거래일 기본 종목정보에서 KOSPI 주권·보통주의 ISIN 전부를 복원한다. 1분기 표본의 추적이나 해당 분기 말에 이미 상장폐지된 종목의 사후 추가를 하지 않는다. 원래 5개 기업, 기존 8개 QC 기업과 새 11개 독립 QC 기업을 모두 제외한다. 앞선 분기에 선정한 종목도 제외하여 총 9개 기업을 별개로 확인한다.

분기마다 세 기업을 뽑는다. 우선 기존 KIND 2021년 3월 기말 반기·사업보고서 목록에서 공시시각이 해당 분기말까지이고 대상 종목코드 앞 다섯 자리가 유일하게 일치하는 기업 1개를 결산월 예외 점검 대상으로 뽑는다. KIND 주기형 보고서는 비12월 결산 또는 단기 결산의 후보 근거다. 실제 회계분기·시작월은 원문에서 확인한다. 나머지 두 곳은 해당 분기 전체 KRX 적격군 중 위 예외 후보를 제외한 모집단에서 뽑는다. 예외 분류를 모든 기업에 대해 완전하게 식별했다는 가정은 하지 않는다. 각 군 내 순위는 UTF-8 문자열 'MR-v2-period-forms-1|' + YYYYQn + '|' + ISIN의 SHA-256 오름차순, 동률 시 ISIN 오름차순이다. 종목 선정에는 주가·실적·미래수익률·자료 확보 가능성을 쓰지 않는다. 선정 후 접근 불가·연결 부재·금융업은 그대로 보고하며 대체하지 않는다.

## 수기 검수와 정정 처리

- 매 분기 당기 및 전년 동일 달력 3개월 *연결* 매출·영업손익 네 값을 독립 원문에서 직접 판독한 뒤 수기표를 먼저 고정한다. 2021Q2는 4월 1일~6월 30일, Q3는 7월 1일~9월 30일, Q4는 10월 1일~12월 31일이고 각각 2020년 같은 달이 비교구간이다. 기재된 기간을 사용하고 보고서 제목의 분기 번호로 추론하지 않는다. 각 기간 시작일/종료일, 3개월·누적 열, 원화 표시단위, 부호, 낱개 항목명, 연결 범위 및 영업중단·재작성 유무를 확인한다. 보고서에 전기 연간·누적만 있으면 해당 열을 3개월로 대체하지 않는다. 비12월 결산은 달력분기와 회계분기 차이를 명시한다. 삼월/구월 결산이라고 해서 특정 보고서 서식을 일괄 가정하지 않는다.
- KRX 역사적 표준코드와 기업명, 거래소 공시 제출자, DART 고유번호·원접수·정정 접수, KIND 문서번호, 원문 URL·SHA-256·공개시각과 이후 첫 거래일을 기록한다. 공시 당시의 원본을 보존한다. 이후 정정의 최초 사용일은 정정 공시일 다음 거래일이다. 각 형성시점까지 도달한 버전만 쓴다. 정정으로 과거의 관측을 덮어쓰지 않는다. 여러 정정의 연결이 불분명하면 보류한다.
- 해당 분기가 회계연도 4분기일 때에는 연결 원문의 독립 3개월 열이 있으면 이를 먼저 판독한다. 3개월 열이 없을 때에만 동일 법인·분기·통화·단위·연결 범위·회계정책·계정 정의에서 **연간 금액에서 같은 회계연도의 9개월 누적을 차감**할 수 있다. 현재 연도와 전년 비교 연도를 각각 검증한다. 두 해의 연간 및 9개월 누적 4개 입력(매출과 영업손익 각각)에 대해 기간·버전·원문 표/행/열·공개일·해시를 보관한다. 전년 비교액은 현재 보고서가 실제 재표시한 비교액의 기준을 사용하며, 전년도 최초 제출액과 다르면 사유와 9개월 소급 조정 근거를 확보한다. 연간/9개월 사이 감사 수정, 재분류, 연결범위 소급 변경 또는 중단영업 표시기준이 다르면 재조정 근거 없이는 누락 처리한다. 같은 연간 파일 두 번 사용, 분할 범위가 다른 보고서의 차감, EPS·비율의 차감은 허용하지 않는다.
- 차감형 값은 최신 구성 문서가 공개된 다음 첫 시장 거래일부터만 사용한다. 9개월 정정이 뒤늦게 나오면 그때부터 재계산하고 과거 값은 보존한다. 독립 검수자가 직접 찾은 4분기 단독 손익 주석·검토보고서 등과 대조가 가능하면 수치와 차이를 제시한다. 별도 직접 3개월 근거 없이 동일한 두 입력을 재계산한 경우 ‘산술 재현·독립 3개월 미확인’으로 분리하며 4분기 방식 전반을 검증했다고 판단하지 않는다.
- 금융업 영업수익을 매출로 대체하지 않는다. 모집단 검증 전에 독립 추출기와 수기 값을 금액·부호·열·단위·가용일별로 비교한다. 1건이라도 잘못 승인하면 해당 서식·신호는 보류한다. 결측/제외 및 모호한 근거는 모두 공개한다. 3개사씩의 결과는 서식 검수로만 해석하고 전수 확보율로 외삽하지 않는다. Q1 게이트가 통과된 후 원문 대조를 시작하며, 그 전에는 후속 실적 원문과 수익률을 읽지 않는다.
