## 판정 방식

KRX 3월 31일과 해당 원본 접수일에 같은 보통주 종목코드와 ISIN이 있어야 한다. 거래소가 해당 공시 사건에 붙인 6자리 종목코드는 KIND ‘상세검색’ 공식 엑셀 내보내기의 ‘종목코드’ 열에서 읽었다. 같은 쿼리의 화면과 내보내기의 번호·시간·회사·서식명·귀속 분기·제출인을 일치시켰다. 내보내기에서 보고서 뒤에 붙는 작은 [정] 표시는 원본 이후의 정정 존재를 알리는 아이콘으로, 원본 앞에 붙은 [정정]과 구분한다. 접수가 다른 정정 건을 원본처럼 사용하지 않는다.

KIND 접수번호와 금융감독원 DART 접수번호는 다른 체계다. 거래소 색인의 해당 원본에 기재된 회사명 또는 제출인, 접수일, 대상 기간, 보고서 종류, 원본 여부를 전시장 DART 원접수와 대조했다. 두 색인 모두에서 행사 대응이 유일해야 한다. 회사명에서 공백·(주)·주식회사·문자 폭만 정리했고 임의 이름 유사도나 수동 가중치는 사용하지 않았다. 현재 사명 단독·유가증권 필터 단독 판정은 사용하지 않았다. 에이프로젠 KIC(007460)는 해당 거래소 원본 20210517001023에 대응하는 같은 날짜의 동명 DART 원보고서가 두 건이어서 보류했다. 3월 및 제출일 ISIN 검증은 연합병·코드 재사용 판단을 위한 조건이며 개별 기업행동 자체의 회계 승인은 별개다.

금비의 KIND/DART 원본은 20210517000778/20210517000724, 방림은 20210517000324/20210517000289다. 양일의 역사적 ISIN을 대조했고 두 기업 모두 5월 17일 공개, 5월 18일 첫 사용 가능이다. 4~6월의 KIND 반기보고서 전체와 금융감독원 반기 XBRL 색인에서 해당 분기 정정 0건이며, 보존된 원본 화면의 각 문서 선택 목록에도 원본 한 건만 있다. 연결 손익계산서의 당기·전년동기 ‘3개월’ 두 금액을 실제 읽었다. 6개월 누적은 별도 열로 남겼다. 기신정기의 KIND 20210610000250, DART 20210610000278 사업보고서는 12개월 열만 있었다. 나머지 연간 보고서의 분기값은 미검증이다. 6월 30일 이후의 모든 정정에 대한 인증을 뜻하지 않는다.

현대약품의 당시 KIND 원접수 20210414000539와 전시장 DART 원접수 20210414001995는 2021.02 분기보고서다. 2021.03 회계분기로 이동하지 않았다. 동성화학(005190)은 3월~6월 KRX 기본정보에서 마지막 관찰일이 4월 15일이고 5~6월 적격 종목군과 분기 공시 검색에 없었다. 마지막 관찰일만으로 청산일이나 특정 정산 수익을 대입하지 않았다.

## 재현

작업 디렉터리는 저장소 루트다. 독립검수 묶음의 원본 KIND 페이지를 풀고 2021년 3~6월의 KRX 월별 보존 원본, 공식 3월 말 모집단 CSV와 전시장 DART 분기 원접수 색인을 사용한다. FSS 색인 재조회는 공개 OpenDART ‘재무제표 원본파일(XBRL)’에서 전체 시장, 20210401~20210630, 반기 11012 및 사업 11011 각각 수행했다. 두 연결 근거와 실제 원문 식별·SHA-256은 identity_nondec.json에 있다.

```bash
PYTHONPATH=research/v2_pit python research/v2_pit/stage82b/identity.py \
  "$MAR31_UNIVERSE" "$ALL_MARKET_DART_INDEX" "$KRX_ARCHIVES" "$KIND_CACHE" "$OUT"
PYTHONPATH=research/v2_pit python research/v2_pit/stage82b/identity_nondec.py \
  "$KIND_CACHE" "$KRX_ARCHIVES" "$MAR31_UNIVERSE" "$OUT/identity_nondec.json"
python -m unittest discover -s research/v2_pit -p test_stage82b_identity.py
```

첫 명령은 비어 있는 KIND 캐시에 화면과 내보내기를 채울 수 있다. 두 번째 명령은 독립검수 묶음의 원본, 포인터, 7개 대체 공시와 반기·사업 원본 색인을 재사용한다. 금융감독원 원문을 직접 열 수 없는 동안 신호 승인에는 별도 본문·범위·시점 검사가 필요하다.
