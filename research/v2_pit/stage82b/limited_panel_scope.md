# 2017~2021 비용 제한 표본의 사전 결정안

이 범위는 전수 수집비용을 감당하기 어려울 때 쓸 보조 연구다. 2021Q1 및 Q2~Q4의 품질 검증과 2017~2021 연도별 품질 게이트를 생략하는 우회 경로로 쓰지 않는다. 전수에 정의한 9단계 주 분석과 결과 표기를 분리한다. 2021 신규 원문 및 어떠한 수익률도 이번 준비에서 열지 않았다. 기존 입력 DB의 공식 거래일·당일 보통주 식별자·종목코드만 읽었다.

**모집단과 표본 고정.** 2017년 1월부터 2021년 12월까지 매월 첫 KRX 거래일에 당시 KOSPI 보통주 전부를 열거한다. 금융업과 상장폐지 예정 종목도 처음에는 포함한다. 각 ISIN에 고정된 salt를 붙여 SHA-256으로 정렬하고 그날 존재하는 종목 중 앞의 240개를 기록했다. salt, 240과 적용 시점은 추출 결과나 미래수익률을 열기 전 고정했다. 신규 편입 종목도 다음 월초에 참여하고 시장 이탈 종목은 마지막 편입 시점까지 남는다. 매달 뽑기를 새로 하지 않으므로 동일 ISIN이 여러 달 유지돼 증빙을 재사용할 수 있다. 단순무작위표본과 유사한 결정적 해시 추출이며, 한 번 정한 salt로 생성한 표본의 대표성에는 오차가 있다.

**실행 규모.** 원래 모집단은 60회, 매월 742~796개, 824개 고유 ISIN, 46,106개 종목-월이다. 240개 제한 표본은 270개 고유 ISIN, 14,400개 종목-월이다. 매월 형성일 직전 180일 이내에 끝난 달력분기와 ISIN의 중복을 제거한 후보는 16,236→5,097쌍이다. 원본 문서 인벤토리 규모 추정치이며 공시가 실제 있는지, 필요 접수번호나 API 호출 수를 뜻하지 않는다. 비12월 결산, 최초/정정 전 버전, 4Q 비교에 필요한 전년 및 9개월 원문, 검색 페이지와 독립 대조, 여러 기업의 동일문서 중복에 따라 실제 호출량은 달라진다.

- 공개 원문 ZIP 1건을 평균 0.2MB로 가정하면 5,097건 약 1GB로, 정정·예외·원문 표시 HTML을 추가하기 전의 계획 추정이다. 8.2 수집기의 시작 간격 0.4초를 적용한 단일 요청/건 시나리오는 요청 시작 간격 합계만 약 34분이다. 전체 실제 경과시간, 완료보장, 서버 허용량 또는 API 무료한도의 추정에는 쓰지 않는다. 승인 뒤 첫 100개 신규 문서에서 실제 평균·중앙값·실패율·재시도·요청 유형별 비용을 기록해 예산을 갱신한다. 서버 일시 오류·제한은 기존 재시도/중단 방식을 사용한다. 결과를 좋게 하기 위한 표본 교체는 금지한다.
- 매월 추출 성공이 아니라 당시 선택을 분모로 보존한다. 업종은 각 형성일 당시 분류를 사용하고 금융업·미확인·비금융을 분리한다. 선택군이 전체 표본의 금융·당시 시총·유동성·상장기간 분포와 얼마나 다른지 성과 조회 전에 기록한다. 해시 추출확률은 해당 월 240/N이므로 전체군 규모 비교 시 가중치를 명시한다. 미확보 분모를 가중치로 지우지 않는다.
- 전수 게이트를 통과하고 연도별 제한 표본의 식별/계정 커버리지도 각각 90%/80% 기준을 만족할 때 시작한다. 120일 주 지평 최소 유효월 36개월은 protocol.md 기준과 같다. 제한패널에서 신호 단독 대조는 월별 유효 상위·나머지 각 5개 이상, 결합 대조는 C와 양쪽 대조 A·B가 각각 5개 이상인 월만 사용한다. 기준 미달 월, 성과 가용률, 유효 기업 수를 모두 공개한다. 신규 상장과 종료 무렵의 120일 검열은 결과 열람 전에 확정한다. 유효월 부족 시 점추정은 설명용, 확증·전략 승격은 보류한다.
- 표본 내 월별 백분위는 표본 내 순위로 이름 붙인다. M4 기준 집단·보유 결과도 같은 표본 및 날짜에 맞춘다. N 전체 상위 20%의 매매성과 또는 KOSPI 전체 알파라고 확대해석하지 않는다. 개발 표본이 유망하더라도 동일 구간 전수 확대는 커버리지·편향 검증이며 독립 확인이 아니다. 2022~2023은 동일 salt로 별도 생성하며 기존 프로토콜을 따른다. 2024년 이후 접근 금지 원칙은 그대로다.

## 원본과 정정의 조회 순서

1. 공개 KIND/DART 정기공시 원본과 수정·재수정 인덱스를 날짜별로 페이지 끝까지 수집하고 중복·결번·공식 페이지 전체 건수를 대조한다. 모집단은 시장 전체 인덱스와 역사적 ISIN으로 결정한다. 현재 상장사만 남은 API 분류에 의존하지 않는다. XBRL 다운로드 목록만으로 정정 및 비XBRL 기업을 완전하다고 간주하지 않는다.
2. 먼저 270개 ISIN을 역사적 법인과 연결하고 각 형성일에 사용 가능한 정기공시 목록을 만든다. 날짜 범위는 초기 2017년의 180일 워밍업을 포함한다. 최신 회계분기→당시 최신 접수버전→필드 가용일 순으로 선택하고, 수정이 더 오래된 분기에 관한 것이면 그 자체가 최신 분기가 되지 않게 한다. 같은 날짜 상충 버전은 공시 선후가 명확해야 채택한다. 차기 월까지 바뀌지 않은 증빙은 재사용한다. 형성 후 정정은 이전 월의 확정 값을 덮어쓰지 않는다.
3. 후보 원본 ZIP·표시 HTML은 접수+문서번호·SHA로 캐시하며 문서·단위·당기 및 전년 해당 3개월·연결 범위를 확인한다. 예전 일괄 재무제표 다운로드는 동일 계정의 최신 정정값이 섞이고 당시 접수·원문 해시와 일치하지 않으면 과거 값 입력에 쓸 수 없다. 원본 링크를 찾아내는 목적으로만 쓸 수 있다. 4Q는 검증된 독립 3개월 또는 quarter_holdout_protocol.md의 엄격한 동일기준 연간−9개월 증빙만 허용한다. 분할·공시 접수 시각·미확정 기업행동이 해결되지 않은 경우 필드별로 보류한다.
4. 성과 조회 전 각 연도·분기·금융/비금융·상장기간·후속 이탈별 원문 식별/추출/정정 추적/월별 가용률, 180일 경과율, 최소 관측 조건 및 매칭 방식을 고정한다. 사업보고서나 반기보고서 등 특정 서식이 구조적으로 빠지면 데이터 게이트 결과에 반영한다. 기존 2021 검수자료를 재사용하고 다른 담당자가 수집하는 원문을 재요청하지 않는다.
5. 다음 명령은 거래일과 모집단만 읽는다. 데이터베이스는 읽기 전용이며 인증기에서 가격·경제·성과 테이블 접근을 거부한다. 현재 압축된 원본이 있는 환경에서는 재구축 없이 foundation ZIP에 보존된 SQLite를 사용한다. 해시가 이미 고정된 선택 명부를 그대로 복원할 수 있다.

```bash
python limited_panel.py /path/to/Morning_Report_V2_PIT.sqlite limited_issuer_months.csv
```

실제 선택 명부 SHA-256 및 연도별 수는 limited_panel_summary.json에 있다. 본 연구용 원문 수집 또는 투자성과 계산을 시작했다는 뜻은 아니다.

### 소규모 변형의 비용과 결합군 크기

수익률 없이 같은 해시의 앞 80·100·120·160개와 240개를 비교했다. 실제 월말 이후의 생존·성과와 무관한 계산이다. 5개년 기준 후보 발행사-분기 수는 각각 1,694 / 2,123 / 2,547 / 3,397 / 5,097이다. 2017~2019 고정 3개년이면 1,048 / 1,316 / 1,577 / 2,105 / 3,156이지만 120거래일 말단 검열 후 기존 36개 유효월 기준을 채울 수 없다.

같은 적격군에서 실적·M4 두 순위가 독립이고 유효 표본이 매월 예정 표본의 70%라고 놓은 단순 초기하분포 시나리오에서 80·100·120·160·240개별 C군 기대치는 2.16 / 2.80 / 3.05 / 4.32 / 6.48개다. C군이 5개 이상일 확률은 각각 2.9% / 10.5% / 15.2% / 44.3% / 83.3%이다. 이는 실제 상관·체결·업종·시총 또는 성공률 추정치가 아니다. 기준을 맞출 때까지 표본 크기나 기간을 바꾸지 않는다. 가장 저렴한 80~120개 구성은 원문 파싱·해시·정정/월 선택 로직의 기술 검증용이다. 240개×5년은 결합군 검정이 가능한지 사전 결정하는 제한 연구 옵션이며 충분한 검정력을 보증하지 않는다.

### 2017~2021 외부 원천 표본 접근

- WISEindex의 과거 일자 G40 금융과 G45 IT 구성에 대해 2017~2021 각각 첫 시장 거래일을 요청했다. 10/10 응답의 TRD_DT, 구성원 수, 중복, 업종코드가 일치했다. 전기간·전 업종 변경 이력의 완전성은 아직 검증하지 않았다.
- OpenDART 공개 XBRL 목록의 2017~2020 매년 5월 첫 페이지에서 100건씩 분기보고서 메타데이터를 확인했다. 2021Q1 기존 전체 인덱스는 재사용한다. 이 목록에는 XBRL이 없는 기업·문서가 빠질 수 있다. DART의 다른 공개 검색 엔드포인트를 동일 역사기간에 시험한 결과 이번 요청은 HTTP 오류, KIND 간이 조회는 정상 공시목록을 반환하지 않았다. 이 결과로 과거 정정 체인 전수 확보를 확정할 수 없다.
- 인증 API 명세는 법인번호 없이 3개월 이내, last_reprt_at=N으로 정정을 포함한 전체 접수를 조회할 수 있다. 5년을 한 요청으로 부르는 방법이 아니다. 실제 키를 이용한 응답은 미인증이다. 공시일 인덱스를 월 단위로 나눠 페이지 전체·중복·원문을 검증하고, 누락되는 시기/서식은 제3자 최신 수치로 보완하지 않는다. 공식 명세 https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001
